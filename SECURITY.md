# Security Policy

## Supported Versions

Only the latest release of `odcs-java-sdk` is currently supported with security updates. We encourage all users to upgrade to the latest version published on Maven Central.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | Yes                |
| < Latest| No                 |

## Reporting a Vulnerability

If you discover a potential security vulnerability in `odcs-java-sdk` or any of its submodules (`odcs-core`, `odcs-spark`), please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

### How to Submit
- Use GitHub's **Private Vulnerability Reporting** feature by navigating to the **Security** tab of this repository and clicking **Report a vulnerability**.

### What to Include
Please include the following details in your report:
- A description of the issue and its potential impact.
- Step-by-step instructions or a minimal code example to reproduce the vulnerability.
- Affected modules or dependency versions.
